## 🛠️ How to Run Locally

### 1️⃣ Install Dependencies
```bash
npm install
```

### 2️⃣ Start Development Server
```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

### 3️⃣ Build for Production
```bash
npm run build
npm run start
```
